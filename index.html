六、公开网站与月度自动巡检

本页可以作为公开静态网站发布。公开站只发布数据来源、链接、状态、报告模板和巡检结果；不公开内部Word原稿、临时解析文件或未经复核的非官方数据。

月度巡检的目标不是自动写正式数，而是发现“哪些公司新发布了集团/母公司全年官方资料”，并形成可复核清单。只有人工确认口径、页码和公式后，才进入第五部分和报告正文。

6.1 公开网站文件

文件 用途 公开说明
index.html公开站首页，自动跳转到主页面。可以公开。
data_sources.html主页面：数据来源、2024回溯、2025状态、公开站说明。可以公开，注意后续不要写入内部备注。
PUBLIC_SITE_README.md部署说明。公开前用于部署检查。
Word原稿、.codex_extract原始材料和临时解析文件。不建议公开。

6.2 推荐发布方式

方式 怎么做 适合情况
GitHub Pages把 index.html、data_sources.html 上传到仓库，开启 Pages。最简单，适合长期公开维护。
Cloudflare Pages连接 Git 仓库，Build command 留空，输出目录用根目录。访问速度和缓存较好。
Vercel/Netlify作为静态站部署，无需构建命令。适合以后扩展成应用。
