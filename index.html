📚 数据来源

国内企业数据来源

  • 各企业年度报告（A股/H股上市公司年报）
  • 企业社会责任报告/ESG报告/可持续发展报告
  • 国务院国资委公开数据
  • 中国电力企业联合会行业统计
  • 国家能源局公开统计数据

国外企业数据来源

  • 各企业Annual Report / 10-K / 20-F
  • Integrated Report / Sustainability Report
  • 投资者关系官网公开数据
  • 三大评级机构（穆迪/标普/惠誉）评级
  • 欧盟碳排放交易体系公开数据

数据口径说明

  • 财务指标：统一使用合并报表口径，按年度平均汇率折算为美元
  • 运营指标：装机容量单位统一为万千瓦，发电量单位统一为亿千瓦时
  • 比率指标：非化石能源占比、资产负债率等均为百分比
  • 特殊财年：日本JERA、印度NTPC财年为4月1日至次年3月31日
  • 排名规则：资产负债率为"越低越好"，其余指标默认"越高越好"
